# 网文新手导航站

> **"不替你做决定，只帮你做分析"** — 帮助想写小说的新手快速了解行业、选择平台、学习写作。

## 项目简介

这是一个为网文写作新手打造的一站式导航网站，解决以下问题：

- 🤔 平台太多不知道选哪个
- 📜 签约规则、收入模式看不懂
- 📝 不知道怎么投稿
- ✍️ 写作技巧需要提升
- 🔍 信息太分散，东一块西一块

## 功能

- **平台对比** — 起点、晋江、番茄、七猫等主流平台横向对比
- **平台详情** — 每个平台的签约门槛、收入模式、适合题材、优劣势
- **投稿指南** — 各平台投稿流程详解（开发中）
- **写作技巧** — 新手入门教程（开发中）

## 技术栈

| 技术 | 用途 |
|------|------|
| [Astro](https://astro.build/) | 静态站点生成框架 |
| JavaScript | 数据处理与页面逻辑 |
| JSON | 平台数据存储 |
| JSON Schema | 数据结构校验 |
| Node.js Test Runner | TDD 测试框架 |
| GitHub Pages | 免费托管 |
| GitHub Actions | 自动部署 |

## 开发方法

采用 **TDD（测试驱动开发）**：

```
🔴 RED    → 先写测试，定义预期行为
🟢 GREEN  → 写最少代码让测试通过
🔵 REFACTOR → 优化代码结构
```

## 本地开发

```bash
# 安装依赖
npm install
cd site && npm install && cd ..

# 运行测试
npm test

# 校验数据
npm run validate

# 启动开发服务器
npm run dev

# 构建
npm run build
```
